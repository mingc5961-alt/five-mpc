# 路线记忆失效概率与多无人机双时间尺度 MPC

## 研究问题

一个基站用一部共享无线电为多架无人机提供下行通信。获得新位置要占空口时间；等待可保留发送时间，但指向会逐渐不准。系统要决定五件事：什么时候值得感知、观测哪架飞机、通信指向哪里、用多宽的束、每架飞机获得多少发送时间。目标是交付尽可能多的有效比特，同时兼顾各机的服务欠账。丢包损失、感知时间、切束时间和预测过期都计入最终成绩。

## 从一条观测到一次资源分配

1. **发布预测。** 某机收到带噪的距离、角度和径向速度。短期滤波器推断当前位置与速度，路线记忆把位置投影到已经走过的空间路径上，预测沿路进度。历史训练的门控对两者按时长融合，形成未来 10 秒的通信指向轨迹。
2. **判断路线会不会失效。** 在每个查询时长，给出“从发布时刻到该时长，纯路线指向曾经让参考 32×32 窄束损失超过 3 dB”的概率。一架飞机可以仍在旧路线上，但进度估慢，导致波束提前或滞后而被判失效。累计事件可以在轨迹重新贴合后继续为真；它表达的是这一整段复用是否曾失败。
3. **估计通信收益。** 分别学习“此前路线已失效”和“尚未失效”两个条件下，使用融合轨迹、不同束宽能实现多少有效 Mbps。用上一步的概率混合两组估计。这一步把预测真正送进决策，风险增大时不同宽度的代价可以有不同变化，调度器可能改束宽、提前观测或重新分配时间。
4. **慢层安排谁值得刷新。** 每次重算跨多个快轮的序列。每个有观测机会的快轮可以空过，也可选一架。算法比较不同序列在扣除感知开销后预计能交付多少比特、各机的服务欠账如何变化。实际只承诺最近一个慢帧，随后重新求解。
5. **快层分波束和数据时间。** 先执行当前轮的观测。如果获得了新测量，当场更新预测与风险。在慢层后续意向下，预测多个快轮，选择各机束宽并求解多轮时间分配，只执行第一轮。真实交付量反馈到服务欠账和下一轮决策中。

## 风险概率如何得到

原始跟踪器每 0.5 秒输出一个预测点，线性插值到 0.25 秒网格。每次发布得到 41 个时长标签。在仿真训练集用真实位置计算参考窄束实际阵列增益，首次损失超过 3 dB 的网格及以后时长均标为 1。网格间的瞬时越界可能漏记。通信收益标签则使用实际门控方向、物理信道、不同子阵和各自 MCS，因而“纯路线失效”与“实际通信必定断开”有不同含义。

额外随机树分类器读入预测年龄、路径匹配残差、航向误差、匹配歧义、进度不确定度、历史兑现误差、路线与 IMM 的分歧和链路几何。对一次发布的概率曲线取累积最大值，再在独立校准网络上进行保序回归。两个多输出树回归器分别拟合两个事件状态下 9 种子阵的有效速率。子阵每个轴可取 8、16、32 个阵元。总发射功率固定，阵列尺寸同时决定宽度与对准增益。

设发布历史为 x、时长为 h、束宽选项为 b。控制器读取的速率为

    R(x,h,b) = (1 − p(x,h)) × R未失效(x,h,b) + p(x,h) × R已失效(x,h,b)

每个条件速率头学习“当前网格点的有效速率”，所条件化的事件是“到这个网格点为止曾发生失效”。模型的监督来自同一发布、同一真实未来和同一通信账本。划分单位是整个独立网络。运行报告给出 1、2、5、10 秒的实际累计发生率、平均预测概率和 Brier 分数。独立测试诊断采用共同预热末段的发布样本；调度改变观测节奏后的分布变化应另做正式验证。

## 两个 MPC 各自解什么

### 慢层

公共时钟根据单次观测成本和预算给出可观测轮。允许放弃某次机会，并将省下的时间用于通信。每个慢层节点包含每机最近一次刷新位置（序列中的轮号）、预计欠账与累计目标。搜索将节点扩展为“等待”以及“刷新任意一架”，再按分数留下若干条序列。默认每个深度保留五条，属于有限宽度搜索。预算按时钟前缀限制，单轮至多刷新一架；空过的名额不跨轮积攒。

未来刷新用确定性近似：用最近可见发布的风险与速率曲线近似同一局部环境，将年龄重置到新的观测时刻。慢层内部用可行的一步通信分配逐轮估值。实际刷新后用新包取代旧曲线。这个近似能在线运行，也意味着它可能低估“新测量揭示新路线”的价值。慢层没有使用未来测量，也没有对未知测量做情景树积分。

### 快层

时长单位为秒，速率为 Mbps，故二者相乘得到 Mbit。设每轮可分配数据时间为 T，各机时间为 a，累计服务欠账为 q，每机每轮目标到达量为 d。窗口内优化“预计总 Mbit − 权重 × 终端各机欠账之和”，满足：

- 数据总时间等于轮长扣掉本轮感知和各机切束开销后的余额。
- 每机至少获得 T × 最低总份额 / 机数；余额由优化器分配。
- 下一轮欠账至少为零及“上一轮欠账 + d − 本轮预计交付量”中的较大值。实际执行时严格按此较大值更新。
- 给定通信中点和预测年龄，9 种束宽占用相同切束时间，选期望速率最大的束宽即可与剩余多轮时间线性规划联合求解。方向沿已发布融合轨迹更新。优化器以轮中点近似速率；物理账本按各机实际发送窗口的有效中点结算。

感知与通信耦合在两个位置：感知挤占当轮的通信时间，也改变后续预测年龄和速率；慢层用通信可分配时间和服务欠账给观测序列打分，快层用慢层计划估计未来可传能力。现版本优化的是观测对象与时机、通信指向/束宽和发送时间。感知本身采用固定测量噪声、时长与成功模型；发射功率固定。服务欠账是面向满缓冲流量的软服务目标，最低时间份额是硬约束，两者不能等同于每机最低速率保证。

## 文件与主要函数

|位置|输入 → 输出|函数体的工作及检查点|
|---|---|---|
|run.py：main、execute|命令、配置、输出目录 → 一个阶段或整条流水线|先校验配置并锁定写目录，按顺序准备数据、训练、闭环、汇总和复核。异常写入 status.json 后继续抛出。|
|mpc/setup_run.py：prepare、build_one|独立分组、网络编号 → NPZ 或场景缓存|多个 CPU 进程生成场景。训练/校准保存特征、标签与速率；测试保存世界和相同起点跟踪器。完整文件原子落盘。|
|mpc/data.py：make_scene、publish|有噪观测历史 → 各机预测包|保持 180 秒预热历史，错开每机观测；复用空间记忆、IMM 和从原平台导出的门控。三类数据使用独立种子命名空间。|
|mpc/data.py：inputs、labels|预测包 → 因果特征；预测包与真实未来 → 监督标签|明确区分在线可见数据和事后评分；为全部束宽使用同一个未来。|
|mpc/risk.py：RouteRisk.fit、profile|训练/校准集 → 概率模型；发布包 → 风险和速率曲线|训练分类、条件回归和独立校准，一次发布后可重复查询。age_mpc 仅用训练集的分时长发生率替换概率。|
|mpc/control.py：sensing_clock、rate_table|预算、未来刷新轮 → 可用名额与期望速率表|预先计算各个未来刷新位置对各机速率的影响，搜索分支共用这张表。|
|mpc/control.py：one_step_allocation、slow_plan|估计速率、欠账、候选动作 → 观测计划|先分最低时间，再按分段边际价值分剩余时间；逐层扩展并剪枝，保留等待动作。|
|mpc/control.py：fast_plan|当前真实发布、未来观测计划、欠账 → 每机数据时间与束宽|构造多时段线性规划，最小时间、感知成本、切束开销一并计入，执行首步。|
|mpc/experiment.py：settle、run_policy|实际分配、外生物理世界 → 已交付 Mbit、时间账本|跨 10 秒上限的窗口按有效部分结算；过期部分计零。记录每机指向、子阵、时间、服务欠账及真实结果。|
|mpc/experiment.py：score_risk、report|共同发布与各策略完整账本 → 两张汇总表、中文结果|通信按独立网络汇总；风险在相同发布点评估，使比较不被不同观测节奏混淆。|
|mpc/audit.py：verify|保存的 CSV、JSON → verification.json|独立重算每轮资源、预算前缀、最低份额、吞吐与概率单调性。|

底层 routeclock/ 和 configs/research.json 来自原平台，仅引入本任务使用的跟踪、物理世界、无线链路与配置组件。assets/route_gate.json 是原门控的数值参数，代码可随本目录迁移。正式实验所用风险和条件速率模型由本平台自己的 train 阶段产生。

## 四种对照回答什么

|策略|观测决定|通信决定|适合回答的问题|
|---|---|---|---|
|rotation|每个允许的机会按机号轮流刷新|同一快层 MPC|高频、均匀感知能达到什么通信结果？|
|myopic|每个快轮只评估本轮收益与服务欠账，允许等待|同一快层 MPC，未承诺的未来观测按等待|慢层多步规划与滚动执行整体有没有价值？这是本平台动态时间分配下的单步对照。|
|age_mpc|完整慢层，只用按年龄统计的失效概率|同一快层 MPC|在相同控制结构、条件速率模型下，个体化概率比平均年龄概率多提供什么？|
|joint_mpc|有个体化概率的慢层多步观测规划|同一快层 MPC|完整机制能否在共享资源下节省感知并改善通信？|

上一版“刷新减等待”用固定 TDMA 与固定观测次数，这里给各机的发送时间和总观测次数均可变化。两平台的吞吐量不应直接相减。若要归因到单一决策，可在同一账本中进一步冻结 TDMA 份额或固定观测序列单独做消融。当前没有加入 Whittle。

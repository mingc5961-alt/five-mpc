# RouteClock 多无人机双时间尺度 MPC 平台

基站用历史路线估计预测何时会失效，并按通信收益协调观测名额、波束宽度与共享发送时间。程序、迁移所需的门控参数与物理模型都在本目录。

- [使用手册](使用手册.md) 包含从零运行、查看进度、分阶段执行、继续中断任务、参数和结果字段。
- [架构与主要函数说明](架构与主要函数说明.md) 给出失效定义、概率模型、两个 MPC 的决策变量、目标函数、交互时序与源码位置。
- [已完成的本地结果](runs/demo/结果报告.md) 包含两组独立 16 机场景、四种策略与概率评分。
- [逐轮复核](runs/demo/verification.json) 记录实际时间与吞吐账本校验结果。

在本目录运行 `start.cmd all --out runs/my_first` 开始一轮新实验。在另一个终端运行 `start.cmd status --out runs/my_first` 查看进度。示例结果可直接阅读。

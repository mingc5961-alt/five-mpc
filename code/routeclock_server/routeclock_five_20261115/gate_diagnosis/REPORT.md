# 门控为何几乎总选路线？长历史、小样本CPU对照

**决定：现阶段可在本地增加针对性航线，暂缓为原门控的单纯扩量租用服务器。** 训练从12条增至48条后，原门控确实走出了权重接近1的状态，但预测效果几乎可以用全体共用的固定权重重现。已有输入包含能排序“IMM可能更准”的信号，尚未稳定解决“在哪一次切换能省下足够多角误差”。

## 1. 复现与评价口径

逐条重建原12条训练、6条验证与原两个三机场景的6条测试航线。核对180次带噪观测后的路线哈希、专家未来位置、原门控16个特征、未来真值和已保存的门控权重。每架飞机在同一预测起点考察0.5、1、2、3、5、8、10秒。本文以每一查询时刻的方位、俯仰误差平方和为损失，跨查询求平均，单位平方度。这与原门控的训练目标对应，区别于上轮报告中的三维平均距离误差。

新增36条独立训练航线和24条独立复核航线，沿用原生成器、历史长度、观测协议与六类行为。每增加6条训练航线，各行为各加1条。复核集每类4条；原测试6条保持不变。以验证集的原物理损失选超参数；新增复核航线未参与拟合或选择。补充以五种分层抽样顺序看训练规模结论是否依赖挑中了哪些路线。未使用原校准集作训练。诊断只在独立目录运行，未修改五模型平台或通信调度。

## 2. 单独看25次IMM占优

[中文逐样本明细](results/25次IMM更准_逐样本.csv) 记录预测时长、当时可见信号、事后误差、正确切换可省的代价及留整条航线得到的识别分数。[完整84个查询](results/original84.csv) 同时保留反例和原始特征。每条训练航线只有一个共同起点，不同时长的胜负彼此相关。

| 事实 | 数值 | 对门控的含义 |
|---|---:|---|
| IMM胜出的查询／全部查询 | 25/84，涉及9条航线 | 两个专家各有适用时刻 |
| 25次全选对，可省的累计平方角误差 | 6.55平方度 | 在这批训练查询上，完美硬切换相对纯路线最多省约4.6%的累计误差 |
| 其余59次全部错选IMM，增加的累计平方角误差 | 490.69平方度 | 单次误切可以抵消多次正确切换 |
| 训练航线11贡献 | 7次，合计5.57平方度 | 约85%的可挽回代价集中在一条无可复用航线上 |
| 训练航线2，10秒预测 | 路线5.24°，IMM 11.82° | 这一条错切就增加112.21平方度 |

例如，训练航线3做5秒预测时，路线支持度0.020、当前匹配残差5.775，事后路线误差0.833°、IMM误差0.694°，已有特征的留航线识别器成功提示IMM。训练航线11做10秒预测时，支持度同样很低（0），但最近六个已兑现的同尺度预测中IMM仅赢一次。原特征识别器给IMM的分数只有0.050；这次恰好是25次中代价最大的一项。可见信号相互矛盾，单看是否识别出多数样本容易漏掉最有价值的一个。

## 3. 哪些信息能在预测时使用

原门控有16个量，包含时长、路线支持度、匹配残差、路线/运动专家的历史误差及当前预测分歧。新增9个量，包含已兑现预测的近期相对误差与胜率、匹配残差变化、速度、IMM创新统计与转向概率、两专家在两个角度轴的有符号差及预测位置协方差之比。回看时仅将此前已经发布的预测与当前或此前实际收到的带噪观测配对；1秒观测间隔下，0.5秒查询用1秒回看作为代理。真实行为类别、未来位置、当前查询的胜负都没有进入模型输入。

| 单项信号 | 原训练AUC | 原6条测试AUC | 新24条复核AUC |
|---|---:|---:|---:|
| 路线支持度较低 | 0.79 | 0.43 | 0.57 |
| 当前匹配残差较大 | 0.81 | 0.54 | 0.67 |
| 最近同尺度已兑现预测中，路线误差相对IMM更大 | 0.66 | 0.58 | 0.69 |
| 路线与IMM的位置不确定度之比较大 | 0.70 | 0.73 | 0.65 |

AUC为随机取一对胜负不同查询时把IMM胜例排在前面的概率，0.5相当于随机排序。排序方向只从原训练集确定。对原12条训练航线逐条留出，用原16特征的胜负分类器，在阈值0.5下提示切换16次，正确15次，找回25个胜例中的15个；却仅覆盖6.55平方度可挽回量中的1.45。加9个特征后找回18次，但24次提示中有6次误报。在原训练查询上，“支持度低于0.5就切换”14次全对；原6条测试同一规则7次全错；新24条中42次判中22次。单项阈值缺乏跨路线稳定性。[单项信号](results/single_signals.csv) · [留航线检验](results/leave_route_out.csv) · [规则对照](results/causal_rules.csv)

## 4. 区分样本量、训练目标与输入

保持两个专家的预测和真值固定；下表为同一批测试查询上的平均平方角误差，越低越好。固定权重从训练集以0.01步长选取，对所有无人机和时长统一使用。

| 原16输入、原角度损失 | 原6条测试 | 新24条复核 | 新复核平均路线权重 |
|---|---:|---:|---:|
| 12条独立训练航线 | 11.101 | 7.985 | 0.9997 |
| 24条独立训练航线 | 10.794 | 7.795 | 0.9462 |
| 48条独立训练航线 | 10.538 | 7.698 | 0.8913 |
| 48条训练，仅用一个固定路线权重0.89 | 10.536 | 7.712 | 0.8900 |
| 纯路线 | 11.103 | 7.986 | 1.0000 |
| 12条训练，每条改取3个起点 | 11.101 | 7.985 | 0.9998 |

从12条扩到48条，两套测试均值均向好。新24条复核上，48条与12条的配对误差差为−0.287平方度，按独立航线重采样的95%区间为[−1.097，+0.288]。48条训练后，在新复核集168个查询里原门控给IMM过半权重的仍为0次。五组分层抽样的原门控在12条训练时，复核误差范围为7.66–11.96；24条为7.71–7.88。扩量改善了初始样本选择带来的波动，现有证据主要支持更稳的平均混合比例。

| 固定48条训练，变更一项 | 原6条测试 | 新24条复核 | 新复核提示IMM／正确 |
|---|---:|---:|---:|
| 原输入＋原角度损失 | 10.538 | 7.698 | 0／0 |
| 原输入＋整体归一化角度损失 | 13.684 | 6.133 | 38／21 |
| 原输入＋按查询相对误差加权 | 13.358 | 11.205 | 52／24 |
| 原输入＋学习胜负 | 14.847 | 7.020 | 50／24 |
| 扩展输入＋原角度损失 | 10.555 | 7.686 | 0／0 |
| 扩展输入＋学习胜负 | 13.909 | 11.351 | 60／27 |

整体归一化对所有数据误差统一除以训练时各半融合的平均损失，保持惩罚候选数值，因而改变了数据与正则化的相对尺度。相对误差目标另按两专家误差量级对各查询重加权，降低高代价样本的相对影响；胜负目标对每次胜负作等权交叉熵训练。三者仍以连续位置混合的真实角误差评价，表中“提示IMM”统一指IMM权重超过0.5。胜负分数作混合权重未必等于最优位置权重。

这些实验揭示了两种不同的困难。让损失更重视胜负，模型确实更愿意相信IMM，但误报的代价足以使原测试误差升高；扩展输入可改变排序，不能稳定降低混合后的误差。另用固定深度3的随机森林检验非线性关系，在新24条上扩展输入得到AUC 0.725、同一预测时长内的平均AUC 0.712；原6条上分别为0.665和0.601。当前历史信息有部分辨别力，现有小样本不足以证明哪种识别器能在不同航线分布下稳定转成收益。[全部对照](results/comparisons.csv) · [分层重抽训练集](results/resampled_training.csv) · [配对区间](results/paired_audit.csv)

## 5. 是否值得扩量

现阶段不建议专门租GPU、仅扩大原门控的训练量。若下一轮继续验证门控，优先在CPU上按预测前可见的困难条件（低支持、最近误差突变、两个专家显著分歧）抽取更多**独立**航线，同时纳入相同条件下IMM切错且代价高的反例。训练可分层，评价保留自然比例、独立航线。至少同时比较纯路线、训练得到的全局固定权重及自适应门控；计算在IMM占优时实际挽回多少平方角误差、在路线占优时错切损失多少，并用留出航线验证净改善。只有相对固定混合也有稳定增益，才值得继续检验窄束期限与通信收益。本轮没有重新运行通信闭环。

复现顺序为平台环境运行 `python gate_diagnosis/extract.py`、`python gate_diagnosis/compare.py`。输出仅写入 gate_diagnosis/results。

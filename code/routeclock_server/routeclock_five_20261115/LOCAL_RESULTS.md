# 租卡前的五模型验证结果

## 样本与运行范围

12条训练路线、6条验证路线、12条独立校准路线、6条测试路线。六个飞行行为各有一个共同测试起点，共组成2个三机任务。每机180次、约180秒历史，闭环服务期18秒。与旧先导试验逐航线配对复核了36条路线的几何哈希与全部501点未来真值。测试结果限于这两个网络。

使用真实冻结Chronos-2；两版共享位置、观测年龄、径向速度和量测协方差，路线版另读同一条可见路线的预测。主表五个误差头共用局部特征、LightGBM家族及相同校准规则。门控用训练路线的7个时长拟合，按任务三折生成样本外训练预测；误差头所见的未来均来自各自的训练数据。

## 固定基线与独立核验

16机、180秒预热及180秒服务、5%共享预算。20个独立验证世界 × 6个可行间隔 × 9种束宽全部完成。最优设置为[32, 32]、2秒，验证均值1243.2701 Mbps。全长度单场非最优候选与常规逐事件模拟器的差值为0 Mbps。18次闭环的最大比特账本偏差为9.09e-13 Mbps；按已记录门控权重重建服务期融合位置的最大误差为0米。

## 研究判断

在六条共同测试路线上，门控几乎把全部权重交给路线。它比纯IMM改善了平均位置预测，当前样本没有显示可辨别的专家切换增益。纯Chronos的平均位置误差最小；为Chronos加入路线后，该项指标反而变差。离线最窄束事后潜力和在线实际吞吐量还取决于误差校准、飞行方向与调度。以正式400条测试航线、30个配对网络检验这些现象的可重复性。

训练集84个“航线起点×预测时长”中，IMM在25个查询上的角误差小于路线专家。在0至1、步长0.01的固定路线权重网格上，训练集与验证集的平均角平方误差都在权重1处最低。训练集纯路线的平均平方角误差为1.678平方度，纯IMM为7.442平方度。整体损失偏向路线与门控饱和相符；哪些可见证据能识别短期专家占优时刻，仍需在扩大训练航线后验证。在本轮两个闭环中，只调间隔与门控联调的净吞吐、窄束占比及失效计数也相同。相对纯路线约7.74 Mbps的差值不足以归因于专家切换。

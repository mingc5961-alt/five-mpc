# 低路线支持度下，什么时候值得切到短期运动预测？

**CPU实验结论。** 低支持度确实会出现在两种截然不同的飞行情形中，但目前七个可观测量组合起来，还不足以可靠识别切换到纯IMM的机会。建议结束以硬切换为主的试验，不为它单独租GPU。连续混合可保留为对照；同训练集选出的简单固定权重仍然是强对手。

## 实际样本、门控与评价

从96条新生成的独立训练候选航线中选12对（24条），加入已有48条训练航线；每条新增航线的全部3个起点×7个时长都用于训练。另用五组随机抽取的24条以及一组行为类型配额与难例相同的24条作为对照。验证另用24条，测试另用48条。训练池、验证、测试与旧航线逐一核对几何哈希。主分析与结果均在本目录，旧模型、旧结果保持原样。[事前设计](PROTOCOL.md)

“低”取当时路线支持度小于0.5。对同一查询，计算真实方位与俯仰预测误差平方和。D等于纯路线的平方误差减纯IMM的平方误差；D≥1平方度定义明显获益，D≤−4平方度定义严重受损。按同一观测起点、相同预测时长、支持度相差≤0.05配对，每条航线最多出现一次。未来真值只用于产生训练标签和事后评估。较大损失端使用更严格的门槛，以便专门纳入误切代价高的反例。

测试按平台设定的六类行为比例生成。48条中有12条节奏固定，三类变速或停留行为各8条，偏离归位和无可复用结构各6条。测试集保留所有1008个查询；其中154个为低支持，15个有明显获益，31个有严重损失。另取5对互不重复的测试航线，仅解释信号。此处自然比例指仿真场景定义的比例。

原门控连续混合两个专家的位置。新切换器在低支持条件下，用浅随机森林估计“从固定89/11混合改为纯IMM能省多少平方角误差”。输入为预测时长、路线支持度、当前匹配残差、此前已兑现的相近时长预测的两专家误差差与IMM胜率、两个专家的位置协方差之比、当前专家角分歧。阈值0、1、4或不切换由自然验证集选定；其他时候使用固定89/11。配对分类器是独立补充对照，仅在训练匹配对的两端学习，按胜负打分。

## 一组两架飞机的例子

下表来自独立测试的第2对。两架飞机在119.5秒之前均按1秒间隔观测，之后都预测未来10秒，路线支持度同为0。“已兑现差”只用预测前已回收到的六次带噪观测，正值表示IMM近期平均误差更小。

|量|切到IMM明显获益的航线21|切到IMM严重受损的航线27|
|---|---:|---:|
|当前归一化匹配残差|4.44|0.82|
|已兑现差（路线误差减IMM误差，度）|−1.24|−7.41|
|此前六次IMM占优比例|3/6|1/6|
|配对分类器的获益分数|0.596|0.761|
|事后纯路线角误差|11.70°|26.10°|
|事后纯IMM角误差|5.14°|30.30°|
|从纯路线硬切IMM，挽回／损失|挽回110.46平方度|损失236.83平方度|

在这对航线上，“匹配残差更大”“IMM在相近时长已更接近路线专家”都有辨别作用。第二架的路线预测本身已经很差，而短期外推更差；支持度为0不能替代对另一位专家的可靠性判断。配对分类器反将严重受损的航线排得更高。此例用于说明机制，两行不代表实际调度器对这两个查询均采取了切换。[全部中文配对样本](results/低支持同条件配对样本.csv)

## 哪些信号能跨航线复现

表中为在配对两边正确排序的次数，平手单独列。训练的联合分数使用留整对验证（拟合时排除两条航线）；测试的联合分数用12对训练航线拟合后一次应用。单项方向沿用上轮诊断，未用测试集调方向。

|可见信号与方向|训练12对|新测试5对|
|---|---:|---:|
|当前匹配残差更大，更偏向IMM|6对|3对|
|过去路线误差相对IMM更大，更偏向IMM|6对|3对|
|近期IMM胜率更高，更偏向IMM|2对，另4对平手|3对，另1对平手|
|路线相对IMM的位置方差更大，更偏向IMM|8对|2对|
|配对分类器的综合分数更高|10对|1对|

这些结果支持把已兑现误差作为诊断量；它在某些时刻能解释选择，但当前样本没有给出足够稳定的触发规则。配对数据主要覆盖长时域。主训练12对的支持差均可匹配到零附近，集中在10秒；测试5对有4对预测10秒、1对预测8秒。[完整诊断](results/paired_signals.csv)

## 自然测试的误差账本

单位均为平方度。“挽回”和“损失”相对相同起点的固定89%路线＋11%IMM混合，加总后两者之差为净挽回。MSE为每查询平均平方角误差。

|策略|测试切换情况|累计挽回|累计损失|净挽回|MSE|
|---|---|---:|---:|---:|---:|
|固定89/11混合|固定权重|0|0|0|4.76384|
|既有48条训练的连续门控|连续调整|6.32|1.22|+5.10|4.75878|
|加入24条难例后重训连续门控|连续调整|8.62|2.15|+6.48|4.75742|
|加入难例，按验证集所选阈值硬切|0次|0|0|0|4.76384|
|同一硬切模型，预设零阈值|正确1、错误6|94.16|83.33|+10.82|4.75310|
|配对分类分数超过0.5就切|正确33、错误74|278.47|738.56|−460.09|5.22028|

验证阶段零阈值切换累计净损失147.23，故事前规则选中不切换。零阈值测试中那一次正确选择正是上文航线21。相对纯路线，只看这7次实际切换，挽回110.46、误切损失73.20；相对89/11，则为94.16和83.33。与原连续门控比较，这7次挽回94.19、损失83.21；余下1001次用固定混合代替原门控，净损失5.26，全部查询净挽回5.72。不同参照的收益不能混算。

按整条航线配对重采样一万次，零阈值相对89/11每查询净挽回0.01074，95%区间[−0.15740，+0.24073]。只有一条航线产生净正贡献；去掉它，余下的六次误切全部保留。只看179.5秒的最后一个起点，3次切换全部受损，合计−52.55。未加入难例的零阈值切换50次、正确16次，累计−77.80。针对性加样主要减少了切换次数，收益仍取决于少数航线。[逐查询输出](results/query_predictions.csv) · [两两参照损益](results/pairwise_accounts.csv) · [配对区间](results/paired_intervals.csv)

**软门控也作了等量对照。** 主难例加样相对既有门控仅改善0.00136平方度/查询，区间[−0.00263，+0.00670]。用相同三起点和新验证集、只在原48条训练上重训，MSE为4.652；随机增加等量航线的五组软门控为4.631–4.688，均低于主难例加样的4.757。纯路线在本次测试的MSE为4.620。切换专用的难例数据并未让原连续门控成为更好的整体预测器。[完整策略账本](results/ledger.csv)

## 时域分散的补充检查与决定

发现主匹配集中在10秒之后，另做一次探索性检查：保持训练增量为24条、保持测试集原封不动，在3、5、8、10秒各选3对难例。自然验证仍选择不硬切；零阈值在测试中切3次、全错，累计损失30.79平方度。该敏感性分析的连续门控MSE为4.73062，相对固定89/11改善0.03322，但在同一批增广训练航线上选出的固定91/9混合反而比它低0.00753平方度/查询。参照权重只用训练集确定。[补充切换账本](results/sensitivity_ledger.csv) · [软门控与固定权重对照](results/sensitivity_soft_intervals.csv)

**研究判断：当前没有充分理由把“低支持即自适应切换到IMM”升级为通信主模型。** 在已兑现相对误差和匹配残差之外，现有观测对于“两个专家谁将犯大错”的判别仍不稳定。保留纯路线与由训练数据选取的固定混合，继续评估误差区域能否可靠确定窄束复用期限，比继续扩充同类切换样本更有依据。本轮评价位置与角度预测，未外推吞吐量。

复现顺序为 prepare.py、experiment.py、check.py、horizon_check.py，使用原平台Python环境。数据和实验脚本全部位于 targeted_switch_cpu。审核脚本按原三维预测位置重算1008个自然测试查询、23种主对照策略，账本最大数值偏差约1.14×10⁻¹³平方度。

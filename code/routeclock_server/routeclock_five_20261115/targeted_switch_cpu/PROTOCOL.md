# CPU针对性门控对照口径

数据生成与测试评价分开。低支持沿用上轮 support < 0.5。以纯路线和纯IMM的未来方位/俯仰误差平方和之差 D = E路线 − E_IMM（平方度）定义两端。明显获益取 D ≥ 1，严重受损取 D ≤ −4。两端门槛用于选择训练难例和解释信号，判别正确切换时任何 D > 0 都算获益。因果输入沿用上轮自动按观测截止时刻计算的特征。

**训练匹配。** 生成96条候选训练航线，六类等量。匹配两个不同实例、同一预测时长、同一观测起点，支持度之差≤0.05，两边都低于0.5。每条路线整个匹配只出现一次，最多12对。优先形成更多对，再取更小支持度差。用原48条训练路线作底，加所选整条航线的3×7查询，不单独重复某个标签。等数量随机加路线作对照（五个固定抽样种子）；另保留只用原48条的模型。

**验证与测试。** 使用两个新的独立命名空间。自然验证24条与自然测试48条按平台配置的六类权重25%、1/6、1/6、1/6、12.5%、12.5%配额生成。起点119.5/149.5/179.5秒，各评七个时长。测试不按支持度、胜负或误差大小挑选；另报低支持子集和最后起点，两者只用于解释。主要评价每航线同权；区间按整条航线重抽。保持原6条网络路线、上轮24条复核路线为有历史结果的补充检查，不参与本次选择。

**模型。** 原48条/原单起点/原验证集重现上轮门控；固定89%路线＋11%IMM。对新增航线同时重训原16特征角度门控和低支持切换器。新切换器在低支持训练数据上用浅随机森林回归“固定混合误差减纯IMM误差”，输入时长、支持、归一化匹配残差、过去已兑现的相近时长误差差与胜率、协方差之比、专家角分歧。200棵树、深度3、叶最小6条查询。所有模型共用独立验证集；回归器以预测净收益超过阈值才切到纯IMM，其他时刻沿用89/11。阈值候选0、1、4、无穷（均按平方度），以自然验证集净收益确定，平局选更少切换。同时报告预设零阈值结果。主候选为针对性加样后的验证选阈值切换器。

补充诊断用匹配两端的逻辑回归识别谁更准（C=0.25），以留整对航线和新测试匹配对评价。另用其概率直接触发纯IMM，候选阈值0.5/0.65/0.8/1，只在自然验证集选择。此诊断只见两端，不能把其输出当作自然总体的获益概率。

**判断。** 对硬切换分别核算相对纯路线、相对固定混合的挽回和误切损失，另计算所有查询实际发布位置相对89/11和现有门控的净误差差。软门控只作连续位置的实际误差分解。以独立航线配对95%区间和单路线影响判断是否值得继续；有信号但净收益不稳定时只支持继续离线诊断，不据此上通信闭环。

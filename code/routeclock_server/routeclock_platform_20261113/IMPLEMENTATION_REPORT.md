## 方法名称与完整数据流

这些名称是本平台的代码标记，不是一组通用的算法简称。I、P、H、C、CR_raw是五种基础位置预测；RC、CR是两种融合后的位置预测。它们首先回答“未来在哪里”。随后独立的误差区域模型回答“可能偏离多远”，调度器才决定波束宽度和下一次观测时间。

| 报告中文名 | 代码标记 | 使用的信息与计算方式 | 在实验中回答的问题 |
|---|---|---|---|
| 自适应IMM运动预测 | I | 用带噪位置、径向速度更新位置和速度；并行维持匀速、左转、右转三种运动模型，根据观测调整模型概率和过程噪声，再向未来传播 | 不建立长期路线记忆，仅靠运动状态能做到什么程度？ |
| 空间路径＋进度预测 | P | 从过去观测建立空间路径片段；结合位置、航向及进度连续性匹配路段；估计沿路线的进度和速度，用巡航、减速、停留三个进度模式预测未来，再映射回三维位置 | 即使飞行速度和停留时间改变，记住路线形状是否仍有帮助？ |
| 时间周期谐波预测 | H | 用多个候选周期下的正弦、余弦以及线性趋势拟合位置随时间的变化；通过观测更新系数和候选权重，预测未来位置 | 旧的时间周期记忆与新的空间路径记忆有什么差异？ |
| 无路线输入的Chronos预测 | C | 真实Chronos-2接收历史三维位置序列、观测缺失标记、观测距今时长；不输入空间路线预测，输出位置分位数，取中位数作为预测中心 | 通用时序基础模型本身能够预测到什么程度？ |
| 路线辅助Chronos原始预测 | CR_raw | 在相同Chronos中增加历史发布时保留的路线预测，以及当前向未来的路径预测、路径不确定度和支持度；取输出中位数 | 在进入最终融合之前，向基础模型提供路线信息是否有用？ |
| 空间路径与IMM学习融合 | RC | 逐个预测时长学习权重，将P与I的位置预测加权平均 | 根据当前证据调整路线记忆占比，能否优于单独使用路线或运动模型？ |
| 路线辅助Chronos与IMM学习融合 | CR | 用另一套学习权重，将CR_raw与I的位置预测加权平均 | 路线信息先经Chronos处理，再结合运动模型，是否还有收益？ |

### 学习门控到底做什么

RC：未来位置 = g_R(h) × 空间路径预测 + [1−g_R(h)] × IMM运动预测。

CR：未来位置 = g_C(h) × 路线辅助Chronos原始预测 + [1−g_C(h)] × IMM运动预测。

两套权重分别训练，每个预测时长h可以使用不同权重。门控是一个16维输入的逻辑函数：输入先标准化，线性加权后经过sigmoid，得到0到1之间的融合系数。训练直接最小化融合位置对应的波束指向角误差，并加入L2正则化；它不以“固定/规律可变/随机”类别标签为训练目标。

门控查看预测时长、路线匹配残差、航向误差、路径匹配歧义、进度不确定度、历史路线支持度、此前发布预测兑现后的误差与样本量、两位专家的预测分歧、减速/停留概率及位置变化对指向角的敏感程度。训练数据按任务分组生成折外预测，再训练下游误差头。

例如，5秒后P预测位置为(100,20,50)米，I预测为(90,30,50)米，RC门控给P的系数为0.8，则融合位置为(98,22,50)米。这只是说明公式的算例，并非实测节点。0.8是融合系数，不是“80%的概率安全”，也不是预测区域覆盖率。

### 位置预测怎样进入感知与通信

上述每个位置预测方法后面接对应的误差区域模型。本轮主闭环使用真实TabPFN-2.5，另有LightGBM对照。误差模型使用诊断信息、查询时长和角度轴标记，估计从当前到该时长的整段最大角误差；再用独立校准任务调整区域尺度。

调度器将位置中心转换成指向角，将角误差区域与9种子阵对应的波束宽度比较，形成“波束宽度＋下一次观测间隔”的候选动作，再在共享感知预算内比较通信收益。新观测到来后，先检查以前发布的预测误差，再更新状态和记忆。

因此，Chronos负责位置预测；TabPFN在本方案中负责预测误差区域；门控负责两个位置预测的融合；调度器负责资源决策。这四个作用不同。

当前路线是利用长期路线证据，并未重新接入早期“固定／规律可变／随机”的显式三分类器。三种位置IMM运动模式和三种进度模式也不是该长期三分类。

### 怎样阅读本轮结果

最终真实TabPFN闭环表比较四条完整方法链：自适应IMM运动预测（I）、无路线输入的Chronos预测（C）、路线辅助Chronos与IMM学习融合（CR）、空间路径与IMM学习融合（RC）。这四条链都继续经过各自训练的误差区域模型和共同调度器，因此最终吞吐量差异包含位置预测及其误差区域的共同影响。仅凭这张表不能把收益单独归因于门控；固定预测中心的误差头比较，以及相同误差头设计下的中心比较，用于进一步分解来源。

P、H和CR_raw是已实现的预测中心对照，本轮最终四方法闭环表没有分别列出它们的独立闭环。F是固定观测间隔和固定波束配置的基线，Z是采用信号质量下界触发的Zhang式对照；Z不是对原论文完整系统的逐项复现。

## 已修复的实现问题

1. 同一路段上的多个交叉候选原先没有分别移动预测中心，现已各自传播。
2. 动作先做全局筛选会错误删除“只调宽度/间隔”的候选，现已先限制后筛选。
3. RC/I训练档案与部署时可得信息不一致，现已移除未执行专家的档案输入。
4. 无档案消融原先只删除误差头证据，现已连门控一起重训和校准。
5. 校准锚点与测试锚点此前的观测时序不一致，现采用共同因果观测协议。
6. 谐波兑现误差、末端连接的桥段距离、事件末尾时间和实际动作图均已补齐。

详细设计对应与两轮审查记录位于 `implement-stage`。第二轮审查后修复的项由执行人通过回归检查确认，原始审查意见保留。

## 效果不足的现象与后续方向

LightGBM的三机验收中，RC未获得持续吞吐优势。该配置只建图12秒，45条RC观测记录中尚无路径闭合记录，长期几何记忆还不成熟。正式180秒建图条件下应重新判断其价值。

同一验收中的Z下界触发产生零吞吐；记录到SNR校准扣减为 **75.15 dB**，使候选动作难以通过门限。后续可先增加训练与校准任务，检查跨束宽的残差分布及区间覆盖，而非直接调低门限。本轮保留失败现象，没有据此改动算法来改善排名。

# 实施目标

依据 2026-11-12 研究报告与 v3 空间进度配置，在独立目录实现可执行研究平台。旧项目只读。
输入：带命名空间的物理任务、真实无线观测、模型权重及训练任务。
输出：预测档案、误差与期限、逐事件通信账本、配对实验统计。
验收：`python -m pytest`；`python -m routeclock.cli local`；真实模型 `probe`；完整实验矩阵 `matrix`。
Base commit: none (new directory, not a git repo).
范围：完整模型、训练/校准、闭环及实验运行器；本地以少量任务执行，正式规模配置保留。
不采用虚构预测、隐式模型替换或免费真值历史。

# 门控、误差管与通感调度的完整训练链

## 数据与训练

1. **从历史位置建立空间路线。** routeclock/memory.py 按位置、航向和进度匹配或扩展路段；沿弧长估计进度，产生纯路线预测 P。routeclock/filters.py 的短期状态滤波产生 I。每架飞机在每个新场景内自行建图。mpc/data.py 的 make_scene 只发布 P、I 等原始信息，并保存预测时刻之后的真值用于离线监督。测试世界与有噪观测源分开保存；控制器只收到所选飞机当下的测量。
2. **训练门控。** mpc/forecast_training.py 的 fit_gate 从独立 gate 网络收集“发布时的 16 个诊断特征、相同时长的 P、I、真实未来位置”。routeclock/predictors.py 的 Gate.fit 从初始化开始学习单层 sigmoid 门控。权重 w 随环境和时长变化，融合中心 RC = wP + (1−w)I。目标为相对基站的方位/俯仰角平方误差加 L2 正则，使用解析梯度与 L-BFGS。门控是原方法中的可训练单层网络；误差管是另一个模型。
3. **训练两轴误差管。** 独立 train 网络的原始发布先经过新门控重新融合。residuals 计算到每个时长为止的最大绝对方位与俯仰误差，角度差处理环绕。tube_rows 为 0–10 秒的 41 个查询点拼上时长、轴标记、门控权重以及发布时可见的运动特征。AngularTube.fit 用同一个 LightGBM 回归两轴对数尺度，并沿时长取累积最大值。
4. **独立校准。** 每个 tube_cal 网络事先随机选一架，使用其末段最后一个采样发布。单个分数是“真实累计误差 / 估计尺度”在所有时长、两轴上的最大值。以第 ceil((n+1)(1−alpha)) 个顺序统计量放大基础尺度。它针对该采样设计下的发布，服务期间调度改变观测分布后应另行检验覆盖率。
5. **估计失效概率与通信收益。** 使用纯路线 P 对准参考 32×32 窄束时，在 0.25 秒网格上首次损失超过 3 dB 构成累计失效事件。RouteRisk.fit 从 train 网络训练树分类器和两组条件速率回归器，在另一个 cal 网络集校准概率。实际 9 种束宽的有效速率标签使用 RC 指向、阵列增益、阴影、MCS 和块误码率重算。失效概率给两种条件速率加权。概率表示纯路线的可靠性，误差管描述实际融合指向的不确定区域。

## 误差管在控制器中的实际作用

每次发布时，beam_deadlines 用校准的两轴半宽得到方向余弦矩形的最坏方向图损失。对每种子阵从第 0 秒向后检查，取连续满足 3 dB 门限的最后一个网格时长。慢层 rate_table 对超过期限的束宽把预计收益置零；快层 Profile.at 只在满足期限的束宽中选取最高估计速率。实际执行采用同一束宽期限裁剪传输窗口。期限过短时，动作可能转成宽束、重观测或未服务时段。三者从同一份真实训练的模型参数计算。这个网格判据不会捕捉 0.25 秒之间未采样的瞬时变化。

## 双时间尺度规划

公共空口同时服务多架无人机。慢层 slow_plan 在多轮内搜索“等待或刷新一架”的序列；观测会挤占通信时间，也会重置该机预测年龄。采用有限宽度搜索。未来尚未发生的测量按当前可见环境曲线估计刷新后的效果，实际测量到达后立即发布新包。快层 fast_plan 在慢层计划下用多时段线性规划分配 TDMA 秒数，目标是预计总有效 Mbit 减服务欠账代价。约束包括感知时钟前缀预算、单轮时间守恒、每机最低数据时间和波束资格。实际只执行首个快轮并滚动更新。功率和测量成本固定。

|入口|主要产物/职责|
|---|---|
|run.py train → setup_run.prepare → forecast_training.train_models|在空目录生成独立样本，训练并保存所有可学习组件。|
|forecast_training.load_models|验证三个文件指纹，从指定目录组合门控、管、风险模型。|
|mpc/risk.py 的 profile|融合、预测误差管和失效概率，生成 9 条时长—速率曲线及期限。|
|mpc/control.py 的 slow_plan、fast_plan|规划感知序列、束宽和通信时间。|
|mpc/experiment.py 的 run_policy、settle|执行真实带噪观测和数据分配，在截止点拆分有效及过期窗口。|
|score_risk、report、mpc/audit.py 的 verify|分别给出误差管覆盖、概率质量、吞吐量和逐轮复核。|

rotation 是轮询观测，myopic 是单步观测价值，age_mpc 只替换个体化失效概率，joint_mpc 是完整双时间尺度方案。四者共用本轮训练的门控、误差管和通信账本。

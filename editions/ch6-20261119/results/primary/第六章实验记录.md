旧主表的 30 个世界中，RC−I 的平均吞吐差为 −18.023 Mbps，配对区间 [−21.869, −14.138]。数据时间项 +0.355 Mbps 的区间跨零，有效速率项为 −18.378 Mbps。旧离线 10 秒预测有显著的路线优势，但在密集观测组，1 秒中心误差两者相近。基于这两组证据，本轮分别操纵训练目标、期限校准以及服务期单次感知成本，并保留相同世界内的对照。

每隔 100 帧重算一次，把已过期限的候选移除，对其余候选从当前年龄至原到期点按梯形法重积分，再用原 value 调度器选动作。该差异同时包含移除到期项、积分区间和离散权重的影响。MCS 回放将同一规划规则应用到实际服务时点；原规划器在预测格点计算候选平均收益。两项回放都固定后续历史，无法估计变更在线策略后的总收益。原始表按时隙开始判定超过刷新间隔，本表按中点判定。P0 表明请求晚到可以出现在候选负载可行的场景中。对能重建前一次决策的 2602 次 RC 刷新，平均晚到 83.60 ms，其中前一次重规划时已晚到 43.36 ms，随后等待 token 再增加 40.24 ms；不能用晚到次数直接归因于预算修复失败。

## P1-a · 门控与包络

- 原代码按每锚点的 `sample_h` 取一个非零时域，训练集共有 3600 个门控样本。报告按每个时域 7200 行的估算不适用于当前门控入口。本轮沿用原采样，以便归因。
- 门控依次设置 G0、按时域 IMM 训练残差均方归一、再加权、G1。加权使用冻结的 case0 RC 三段数据时间比例 0.744012 / 0.184835 / 0.071153；每段质量均分给段内训练时域，并校正该时域样本数。该参照来自旧测试场景，所以覆盖新世界的确认必须独立进行。
- G1 以同一发布时间的上下文计算两个线性头，使用正斜率和 log(1+h)。两个头对 P/IMM 历史误差系数施加方向约束。加入最近 8 个观测间隔的平均值。旧锚点从原数据生成器的观测时钟重建，只使用发布时间之前的时间戳，并逐锚点校验观测计数和原点。各门控用训练路线分组三折得到训练尺度头的折外中心；验证集选择正则强度。完整训练入口可给全部五个中心统一配置 local 或 full 特征。
- 每个候选 Δ 在 400 条独立校准路线（每路线一个锚点）上分别计算双轴、全前缀最大归一误差的有限样本分位数。候选的整个区间共用该 Δ 的因子，10 秒因子与原全局标定一致。`recalibrate` 对冻结旧头逐中心验证这一等式。不同 Δ 的边际覆盖与调度选中后的条件覆盖分别统计。闭环以每个不同的（用户、包原点、选中 Δ）为一次，使用事后完整轨迹评分，保留逐期限分母；覆盖和实际 3 dB 失效分开。
- 已训练的近期密度 G1 模型为 `results/g1_recent_local_delta/bundle.pkl`。用 `--use-calibration global` 和 `deadline` 可在同一组中心、同一组尺度头上隔离校准效应。旧 G0 校准模型为 `results/g0_local_delta/bundle.pkl`。

旧 RC 服务历史上的同历史回放，用旧日志的时隙、动作、观测时间和真实角度，只替换融合中心。数值为按数据时间加权的双轴角 RMSE（度）。

| 预测年龄 | G0 | G1 | 同历史 IMM |
|---|---:|---:|---:|
| 0–1 秒 | 0.21585 | 0.18581 | 0.19008 |
| 1–2 秒 | 0.19732 | 0.18360 | 0.28834 |
| 2–10 秒 | 0.19467 | 0.20631 | 0.35546 |

旧场景短年龄指标达到报告提出的诊断目标，长年龄段 G1 有退步。0–1 秒的 P/I 有符号误差相关系数按方位、俯仰分别是 0.386 和 0.256，本场景没有支持报告用于演算的 0.95。独立于该回放，原离线验证集 400 路线使用**终点二维误差范数均值**，0.5 秒 G0 / 仅归一 / 加权 / G1 分别为 0.3712 / 0.3591 / 0.3475 / 0.3532°，10 秒为 3.5961 / 3.5769 / 3.6711 / 3.7917°。G1 使 0.5 秒平均路线权重从 0.953 降到 0.682；5 和 10 秒的误差代价值得单列。G3 暂缓，先看不同验证世界的短龄指标及长时域损失。

## P1-b 与 P1-c · 配对设计

维持 16 架、5% 服务预算、180 秒预热和 180 秒服务。单次成本取 3.1、6.2、12.4 ms，对应均匀刷新间隔下界 0.992、1.984、3.968 秒。下界只描述均匀刷新的间隔，实际被服务时的预测年龄须从时隙日志测量。

| 阶段 | 受控改动 | 判别问题 |
|---|---|---|
| 机制对照 | 同一工作点，G0/G1 × 全局/按 Δ，固定 local 头规格；随后全中心统一改 full | 短期中心、包络、认证时长、选中动作覆盖、窄束时间和吞吐中的哪一环改变？ |
| 成本扫描 | 固定低成本预热只改服务成本；全生命周期用该成本预热和服务。3.1 ms 两条线共用同一行 | 计算每个世界的 (RC−I)高成本 − (RC−I)低成本，区分服务资源竞争与路线学习稀疏化 |
| 调度归因 | 同一 RC、无线模型、前沿生成和世界，比较 EDF、统一加宽与 value | EDF 用各自最高速率候选、按最早到期服务；统一加宽使用共同方形束宽；value 用速率/负载代价。记录计划负载、超期、失效、最差两机和吞吐 |
| 独立确认 | 在 chapter6/validation 的 20 个世界选配置，各工作点用相同验证世界给 F 枚举所有预算可行的周期和束宽；自适应策略在各自候选集上重新选动作 | 冻结门控、误差头、校准、调度及 F。chapter6/test 的 30 个新世界配对 I/P/RC/F；预先固定前 10 个世界抽查 C/CR_raw |
| 后续控制 | 若 interval_only 优势在 G1 后保留，固定中心和头，比较硬 3 dB 约束与期望 goodput，并加入 Z 的质量下界触发对照 | 用独立训练残差估计联合方向损失分布、同一 MCS/BLER 链路模型积分；给定业务允许失效率后报告可靠性–吞吐曲线 |
| 独立 MPC 线 | 在新增训练/验证世界回放并校正刷新后状态近似，再比较 2/4/6 秒慢窗口 | locked 价值预测 MAE 10.482 Mbit、偏差 −3.387 Mbit。原表 9 个漏报对应首时隙；locked 窗口为 33 个漏报和 6 个误报。按世界留出，报告 MAE、符号命中、吞吐、可靠性、运行成本 |

新服务边界统一重置 TDMA 轮次及 token bucket，所有方法在同世界同协议获得相同时间戳和量测。3.1 ms 的新基线也按此边界运行。训练改动会改变后续观测历史；只有同历史回放能把中心误差变化单独归给门控。新测试世界每场先求配对差、再按物理世界 bootstrap 2000 次；一个世界的试跑不出显著性区间。未指定业务非劣界限，正式比较并列报告几何失效、窄束和最差两机吞吐。后续容量匹配的 CR-G 留作投稿前验证，时间谐波对照限定在离线，规模、阵列和 TabPFN 扩展暂缓。

## 运行入口

在本目录运行。新实验选择独立输出目录；下面命令中的输出名可用于后续复查。原始模型文件路径及每次任务参数保存在对应的 arguments.json。正式实验的原始结果与本目录的 validation、smoke 分别存放。

```bash
py=/data/chen/server_assessment/venv/bin/python
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
"$py" -m pytest -q
"$py" tools/ch6_experiment.py train --gate g1 --head full --calibration deadline --out runs/g1_full
"$py" tools/ch6_experiment.py offline --split validation --bundle runs/g1_full/bundle.pkl --out runs/g1_full_offline
"$py" tools/ch6_experiment.py case0 --cost-ms 3.1 --bundle results/g1_recent_local_delta/bundle.pkl --out runs/case0_g1
"$py" tools/ch6_experiment.py select-fixed --cost-ms 12.4 --warm fixed --out runs/fixed_high
"$py" tools/ch6_experiment.py network --method F --cost-ms 12.4 --warm fixed --winner runs/fixed_high/winner.json --out runs/validation_F_0
"$py" tools/ch6_experiment.py network --method RC --scheduler edf --cost-ms 12.4 --out runs/validation_edf_0
"$py" tools/ch6_summary.py results
```

`ch6_matrix.py validation` 生成验证命令清单，`confirmation` 生成独立测试清单。两者均需要指定 `--root`、`--bundle`、`--calibration` 和本地 Chronos 的 `--checkpoint`；确认清单复用相同 root 内验证出的 F。完整展开每种冻结模型配置为 5 组工作点；验证 540 场加 5 个 F 网格选择任务，确认 760 场（含调度两臂）。先完成有判别力的验证臂，再决定进入确认的冻结模型。不同门控的闭环对照均须使用对应折外重训的尺度头。新世界矩阵和等待验证的机制不计入下面的实测结果。

## 首轮完整世界结果与排期决定

以下各行均为新世界 `chapter6/validation/0`，每场 16 架、180 秒预热、180 秒服务。共有 12 个完整策略运行，独立世界数为 1。短冒烟测试另存。成本扫描保留原模型、全局包络和 value 调度器。

| 预热 / 服务成本 | I 吞吐 Mbps | RC 吞吐 Mbps | RC−I Mbps | I / RC 保持段失效 |
|---|---:|---:|---:|---:|
| 3.1 / 3.1 ms | 1198.93 | 1182.36 | −16.57 | 0.158% / 0.155% |
| 3.1 / 12.4 ms | 468.51 | 506.56 | +38.05 | 2.596% / 0.168% |
| 12.4 / 12.4 ms | 433.07 | 467.86 | +34.79 | 1.430% / 0.945% |

固定相同预热观测后，提高服务成本使本世界的配对差改变 +54.62 Mbps。全生命周期稀疏预热对应 +51.36 Mbps。两条线都出现符号翻转，两种方法的绝对吞吐都大幅下降。固定低成本预热在高成本点使 RC 的全网吞吐较 I 高，但最差两机平均吞吐为 17.87 对 19.78 Mbps。6.2 ms 保留为判定转折位置的中间点。

在 12.4 / 12.4 ms 固定世界、共同 local 头特征规格和 value 调度器的对照如下。G1 带来的变化包括按新折外中心重训的 RC 尺度头。I/P/C/CR_raw 的 LightGBM 树和七个校准因子逐一核对后与 G0 相同。

| 方法 | 全局 → 按 Δ 吞吐 Mbps | 全局 → 按 Δ 保持段失效 | 按 Δ 选中动作覆盖 | 按 Δ 窄束时间 |
|---|---:|---:|---:|---:|
| I | 433.07 → 456.50 | 1.430% → 3.434% | 83.29%（844 个） | 0.43% |
| RC，G0 | 467.86 → 543.77 | 0.945% → 1.107% | 93.55%（899 个） | 1.77% |
| RC，G1 | 487.07 → 580.04 | 0.742% → 2.043% | 91.63%（896 个） | 2.77% |

相对 G0 全局基点，单换门控及配套尺度头 +19.22 Mbps，单换期限校准 +75.92 Mbps，合并 +112.18 Mbps。三个增量都来自同一世界，交互效应仍须多世界复核。G1 的 0.5 秒期限因子为全局因子的 69.0%，1 秒为 75.1%，10 秒为 100%。吞吐改善伴随几何失效率上升；I 的选中覆盖低于 90%，建议在新校准路线复核条件覆盖并按期限、预热协议报告样本量。不要用校准样本上的分位数反推在线覆盖。

同一 G0、全局包络、12.4 / 12.4 ms 下，EDF / 统一加宽 / value 的吞吐分别为 **1061.79 / 317.90 / 467.86 Mbps**，保持段失效为 **28.706% / 0.144% / 0.945%**。EDF 的窄束时间为 87.50%，实际感知占比为 5.0013%；桶初始的一次观测信用允许服务期占比比 5% 略高。EDF 不做规划负载修复，执行仍受同一个桶约束。高收益与高失效并存，不能按吞吐单列选择调度器。下一轮控制实验应同时记录已过请求期限的驻留收益、失效片段和受服务最差两机，再比较统一 MCS 口径下的期望速率与可靠性取舍。

**下一批顺序**：先取同一批新增验证世界，补齐成本三点及两种预热，使用旧模型冻结对照；并行在验证侧比较 G0/G1 × 全局/按 Δ、各方法统一 full 头以及固定动作复选。逐世界核对吞吐拆分、条件覆盖、失效和公平性后，冻结需确认的候选。调度比较保留 EDF、统一加宽、value 三臂。上述 12 场之外的多世界实验均为排期，后续统计以物理世界为单位。每个工况的命令见 `验证任务清单.csv`，实测行见 `results/world_metrics.csv` 和 `results/cost_interaction.csv`。


## 离线验证与核验

完整 G1 + local + 按 Δ 离线有效性表已在原有 400 条验证路线、1200 个锚点重新生成。RC 在各固定 Δ 上的前缀覆盖范围为 90.25%–92.67%。32×32 窄束可发布 1058 / 1200 个锚点，平均认证期限 1.770 秒（未发布记零）；在已发布子集，选中期限的前缀覆盖为 90.83%，3 dB 提前失效为 1.61%。这里使用模型选择阶段的验证路线。独立新世界的闭环统计另见上表。五中心明细位于 `results/g1_deadline_offline_validation/summary.csv`，七个期限的明细位于同目录 `prefix_coverage.csv`。

27 项测试通过，涵盖原有物理和时钟契约、向量化方向图与逐点标量核对、门控单调性、前缀校准和服务期切换后固定动作网格与真实仿真一致性。下批仍需完成多世界工作点和调度比较、全中心 full 头闭环复核、新世界 F 网格择优与独立测试确认。期望速率、Z、MPC 残差修正及窗口扫描处于设计阶段。

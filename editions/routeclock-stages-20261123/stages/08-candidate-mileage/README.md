# 候选专属里程、辅助监督和新世界复验

从上阶段联合模型出发，比较继续训练、里程监督、候选专属进度、两者合用。主确认世界 50–59；60–69 单独复验中心。12 组微调、150 场主闭环。20 个新世界中，联合模型 10 秒位置误差为 Chronos-2 的 1.714 倍；逐世界与留一分析保留全部样本。

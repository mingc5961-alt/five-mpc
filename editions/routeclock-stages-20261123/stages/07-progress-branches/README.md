# RC 沿线进度与路线分支

原 IMM/门控上加入沿线路程和历史走法；四种机制、12 组训练。世界 40–49，7 系统 × 3 预算 × 10 世界共 210 场；另含 400 条离线测试路线与 59 架次 AMOVFLY 的共同历史评分。10 秒新世界均值从原 RC 的 19.75 m 降到 14.62 m，Chronos-2 为 8.80 m。

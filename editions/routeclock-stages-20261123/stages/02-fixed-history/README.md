# 第六章与固定历史修订

配对世界、同一起始观测历史、预算压力与公平性复核。固定历史版累计 2,080 条科学记录，140 条基点记录跨协议复用。两版原始包各有独立标签。可选 runtime 分包保存 paired600 的冻结世界与预热状态。

历史正式包与原版本说明见 [对应 Release](https://github.com/mingc5961-alt/five-mpc/releases/tag/ch6-fixed-history-20261119)。

本页收录 89 个可在 GitHub 查看和比较的源文件。[打开代码目录](code/)

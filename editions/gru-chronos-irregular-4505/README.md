# 非规则机群的 GRU 路线门控与微调 Chronos‑2 闭环对照

16 架飞机中有 10 架无可复用路线。在相同感知预算下，按角误差选择配置的 GRU 路线门控，在两个确认世界的平均期望总风险 **4.505208%** 处，相对**微调 Chronos‑2、已校准原生管倍率 1.00**，全站净吞吐增加 **162.73 Mbps**，有效窄束服务增加 **3.83 秒**。这个比较使用确认集实测曲线选取共同风险和整回合混合概率。

|---|---:|---:|---:|
| 微调 Chronos‑2，原生管 ×1.00 | 4.505208% | 1064.72 | 24.87 |

## 风险如何对齐

五组方法分别为微调 Chronos、按角误差和按全站净吞吐选型的两种 GRU 门控、相应的两种 IMM 门控。两种 IMM 选中同一配置，共有四条不同曲线。每条曲线有四个倍率，每个倍率在相同的两个世界运行，共 32 个闭环回合。

各倍率先对两个世界等权平均。五组都能通过整回合混合达到的风险区间为 **[4.284722%, 5.871528%]**，未缩放 Chronos 的风险落在区间内。主比较将 Chronos 固定为 1.00 倍。在该目标风险上，GRU 的最高期望吞吐来自 **27.1198% 的回合使用 0.55 倍，72.8802% 使用 0.75 倍**。上表用原始端点加权，单个回合内使用同一倍率。两种方法实际占用感知时间分别为 GRU **2.647 秒**、Chronos **2.661 秒**。

**结果的适用范围。** 这一工作点上，两个种子的 GRU 相对原生管基线都有正吞吐和正窄束时间差。在该表的五组方法中，仅按角误差选型的 GRU 同时超过原生 Chronos 的吞吐与窄束时间。按吞吐选型的 GRU 为 1183.94 Mbps、19.63 秒。风险在两世界平均后对齐，逐世界风险仍有差别。允许 Chronos 同样选择管宽倍率后，GRU 的差值变为 **−86.57 Mbps、−36.03 秒**。两种口径应一同引用。把确认集选出的概率冻结后在更多全新航迹验证，才可评价迁移性。

## 场景与指标

- 180 秒共同预热，随后服务 180 秒。16 架飞机中，有 10 架无可复用路线、3 架局部绕行再汇入，其余 3 架分别为全局变速、分段变速、分段变速含停顿。确认世界种子为 0、1。
- 服务期全站感知预算约 3 秒，每次刷新消耗 3.1 毫秒。各方法共享无线配置与调度规则，服务期间由各自闭环决定何时刷新。Chronos 使用微调种子 7、180 秒坐标历史与已校准原生分位管。GRU 使用 IMM 外推加最近 8 秒的位移残差，与在线路线专家按期限融合，再独立校准双角误差管。
- 总风险按所有用户的公共探针统计，计入动作不可用或实际指向损失超过 3 dB。净吞吐用所有成功比特除以整个服务时长。有效窄束时间只累计实际分配给数据、阵列为 32×32 且实际指向损失不超过 3 dB 的时间。

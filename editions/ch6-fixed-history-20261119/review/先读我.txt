按问题读取
1. 核心数字：report.pdf、data/合并逐场指标2080.csv、verify.py。可用装有 pandas 与 numpy 的 Python 运行 python verify.py，此脚本也可作为独立实现的交叉检查。
2. 共同历史及起点预测：data/固定历史逐场指纹.csv 和 data/服务起点预测逐机.csv。同一世界内的飞行器、时域和方法属于重复测量；统计单位是世界。计算起点误差时，先在各世界内平均 16 架的双轴 MSE 再开方，最后在世界间配对。条件包括末次观测的新鲜度。
3. 设计与代码：design/ 中的实际清单、协议、模型选择和固定动作证据；code/tools/ch6_common_history.py、ch6_history_boundary.py、ch6_experiment.py、ch6_cache.py；code/routeclock/ 中的 predictors、simulator、scheduler、holding、radio、memory、validity、evaluation。analysis/ 保存原发表分析脚本。审查数据生成与筛选时，应同时阅读实验实现与分析实现。
4. 原始输出抽查：raw_pair/ 是世界 22、12.4 ms、RC 的两种预热，包括原始指标和参数。涉及其他世界或全部逐机分组时，可到同标签完整补充包及上一个标签的原始归档取数。训练与闭环完整复跑还需对应模型、历史输入与运行环境。

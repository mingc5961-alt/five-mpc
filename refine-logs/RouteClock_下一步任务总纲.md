# RouteClock 下一步任务总纲

本轮有三个主问题。A 检验 F 与 RC 在同等波束稳定性下的净吞吐，B 检验先进模型自己的误差输出能否改善束宽与期限决策，D 检验路线记忆在真实重复和多样飞行中的收益与失效条件。C 用于机制归因，E–G 按论文主张取舍。以下均为待做任务，运行量是预算建议。

## A　在相同波束稳定性下比较 F 与 RC 的净吞吐

- [ ] **A1　统一稳定性计量。** 在同一服务窗内，按同一绝对时钟逐机评分。当前没有可执行波束，或相对同子阵列完美对准的增益损失超过 3 dB，均记为几何不稳定。探测网格只用于结算。另列实际数据时隙中的不稳定比例、连续不稳时长、最差用户，以及原报告的保持段失效率。不同方法切段次数不同，旧指标单独使用会影响公平性。
- [ ] **A2　统一期限、回退与链路结算。** 区分建议刷新时刻和允许执行的截止时刻，固定到期未获刷新时的回退规则。核对调度估值与实际传输的 MCS 规则，记录请求期限、实际使用时长和过期服务。按整个服务窗统计预计成功交付的比特，计入感知、切换、回退与等待。共享感知预算上限，允许各方法实际占用不同。
- [ ] **A3　把 F 调到足够强。** F 用 IMM 更新指向，子阵列和刷新周期固定。对预算可行的宽度、周期做网格搜索。在现有 16 机、单次 3.1 ms、预算占比 1.667% 的离散设定下有 36 个组合。RC 独立调节误差包络放大系数、期限上限等。用少数正式仿真抽查快速网格结果。
- [ ] **A4　先选工作点，再独立确认。** 画出两方验证集上的风险—净吞吐前沿，预先锁定风险目标、可接受的稳定性差和主要工况，在共同风险带内各选吞吐最高的可执行配置。用相同新世界逐对比较。例示判据为风险差的 90% 区间完全落入约定等效带，同时 RC−F 净吞吐差的 95% 区间下界大于零。两个条件分别回答“足够接近”和“谁更高”。仅达到同一风险上限时，按共同上限报告。没有共同支持的工作点时，报告前沿和覆盖范围。

**交付**：一张风险—净吞吐前沿图，一张独立测试主表，以及感知占用、窄束有效数据时间、最差用户速率的收益分解。

## B　让先进模型自己的误差预测决定束宽和可复用期限

- [ ] **B1　统一预测包。** 每次发布输出未来 0.5–10 秒各时域的位置中心和对应误差尺度。在线只用当时已观测历史；训练或校准时用后验真值构造误差标签。为所有方法记录输入通道，显式标注路线协变量和训练权限。
- [ ] **B2　接入模型自身误差。** Chronos-2 现有适配器已提取 q10/q50/q90，保留分位距并投影到方位、俯仰误差尺度。Moirai-2 用其自身分位输出。VECTOR 用历史速度和 GRU 预测运动，在自身隐层增加分时域双角误差分位数头，用样本外中心残差训练。分别标注冻结预训练主干、目标域训练和校准的成本。
- [ ] **B3　校准整段风险。** 对每种模型，在独立校准路线上估计从发布时刻到候选期限、两角轴同时被包络覆盖的程度；同时报告包络宽度。重点复核实际选中的期限，尤其是 8 秒和 10 秒。单轴单时刻分位数无法直接给出整段联合覆盖率。
- [ ] **B4　让误差分数参与真实动作。** 共享控制器逐档检查候选束宽，在整段几何增益损失界满足 3 dB 条件时给出可行期限，再由同一刷新调度器选择动作。记录哪些束宽可用、请求与实际期限、有效窄束数据时间、净吞吐。以同一个预测中心配“模型动态误差”和“仅按时域固定误差”做消融，使动态误差的决策价值可度量。
- [ ] **B5　做两层比较。** 固定历史离线比较中心角误差、联合覆盖和包络宽度。正式闭环比较 RC、Chronos-2、VECTOR、Moirai-2，各自输出中心与误差，接入同一束宽、期限、到期回退和调度逻辑。每个方法可产生不同动作和后续观测历史。以验证集独立选取模型及误差头，统一选型权限，公开各臂选型成本。

**交付**：一张模型表，把角误差、包络宽度与覆盖、实际期限、波束宽度、净吞吐和端到端尾延迟放在一起。

## C　用少量消融辨认贡献来源

| 对照 | 可以回答的问题 |
| --- | --- |
| IMM、单独路线专家 P、路线专家与 IMM 门控的 RC | 哪些航段需要路线记忆，哪些航段依赖局部运动外推，融合收益出现在哪里？ |
| 普通 Chronos-2（C）与接收因果路线协变量的 Chronos-2（CR_raw） | 同一预测家族得到历史路线信息后，预测误差或系统表现是否改善？ |
| CR_raw 与该专家再和 IMM 门控融合的 CR-G | 给路线条件 Chronos 专家加入 IMM 回退后，整个方案是否获益？融合后的误差需要重新估计。 |
| CR-G 与 RC | 两方保留同结构门控、同一个 IMM 和控制器，替换路线专家后谁更有效？固定历史比较中心可缩小归因范围，主表则保留各自校准后的真实系统表现。 |
| 不接收路线信息的 Chronos-2 + IMM 门控（可选） | 在有同类门控回退的条件下，单独核验历史路线信息的增量价值。门控输入也须去除路线信息。 |

若 CR-G 追平 RC，进一步比训练量、尾延迟和跨航线迁移；若落后，查中心角误差、融合后覆盖与推理延迟；若领先，把专家选择与共享控制机制分别报告。首轮可只给 Chronos 增加门控消融。

## D　第三个主问题：真实重复航线与多样飞行中的路线记忆

同一路线跨天或跨架次重飞、单次飞行内反复绕圈、同一业务按固定时间间隔发班，是三种不同的数据要求。前两种分别验证跨架次记忆与架次内记忆。若进一步主张固定发班周期，还需要实际起飞时刻和间隔分布。多样飞行按预先确定的规则抽样，让路线相似度自然变化，保留可重复与难复用两端。

| 数据角色 | 首选与可复核依据 | 优先回答的问题 |
| --- | --- | --- |
| 多旋翼跨架次重复 | CMU AirLab 的 DJI Matrice 100 配送基准，共 195 次航线飞行和 14 条悬停或空闲记录。三角航线改变速度、高度和载荷，合并遥测约 5 Hz，有逐架次参数与日期。[论文](https://www.nature.com/articles/s41597-021-00930-x) · [作者下载页](https://theairlab.org/energy-dataset/) | 同一航线在转弯、停顿和速度变化下，需要多少次历史飞行才有收益？ |
| 固定翼多圈周期路线 | IDF-DS 论文报告 240 次自主飞行，有反复飞行的折线和赛道式闭环。记录同一架次内的圈号，统计时保留架次分组。[论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12982758/) · [数据 DOI](https://doi.org/10.5281/zenodo.16992975) | 第一次过弯到后续各圈的指向预测改善多少？跨架次是否还能迁移？ |
| 多样实飞主样本 | PX4 Flight Review 提供跨机型、飞行模式和硬件的公开用户日志，可以按属性下载；先冻结抽样时间范围及日志清单，再按轨迹形状打分。[官方说明](https://docs.px4.io/main/en/dev_log/flight_log_analysis_statistical) · [日志入口](https://logs.px4.io/browse) | 在预先没有筛选路线重复性的室外多旋翼样本里，多少合格航段能找到历史路线证据？没有证据时门控要付出多少代价？分母限于所抽样本。 |
| 有任务记录的外部核验 | BAMBI 的奥地利野生动物调查包含 389 组视频序列，作者报告约 45 小时；原始包按 flight ID 分开，含 AirData 飞行日志。DroneLog 提供室外无预设轨迹的多平台飞控日志及载荷事件，部分文件跨目录重复，按校验值去重。[BAMBI 项目](https://github.com/bambi-eco/Dataset) · [BAMBI 原始包](https://zenodo.org/records/18885436) · [DroneLog 项目](https://azamatjon11.github.io/DroneLog/) · [DroneLog 数据说明](https://github.com/Azamatjon11/DroneLog) | 在有业务背景的飞行或无预设路线的人工操作中，复用和回退是否仍然有效？原生定位频率与可用长度按文件核验。 |

| 层次 | 要做的事 | 能交付的证据 |
| --- | --- | --- |
| 数据验收 | 先抽 CMU 配送多旋翼和 PX4 多样实飞，再加 IDF-DS 多圈。核独立架次、日期、路线关联、位置更新间隔、缺测、可用连续时长、坐标系和站点几何。 | 明确哪些架次可做短期预测、跨架次复用或闭环，记录剔除原因。 |
| L1 离线预测 | 保留真实时间和运动尺度，转换为站点相对坐标，按独立飞行划分开发和测试，按期限比较方位与俯仰误差。 | 在真实飞行偏差下，路线记忆是否改善指向，尤其在转弯、偏航线和长时域。 |
| L3 历史积累 | 同一目标飞行分别提供先前 0、1、3、5 次合格历史，样本足时加 10 次。跨架次保留路线记忆，每次重新初始化局部状态。 | 记忆在多少历史后开始有用，偏离旧航线时能否及时退回 IMM。 |
| 多样路线与回退 | 预先筛出真机、室外、定位有效的飞行，排除仿真，冻结日志 ID，不依路线规则性选样。按可用历史、路线匹配及后续偏离分层。跨地点不拼接路线记忆，缺少可靠跨架次关联时只评架次内重访和冷启动。 | 用 RC−IMM 的角误差、错误启用记忆后的 3 dB 越界与回退延迟衡量代价。按独立架次或地点报告区间。 |
| L2 轨迹驱动闭环 | 选择长度合格的航段，预先锁定站点，先保持原信道和预算，比较 F、RC 和代表性模型。多个独立架次合成多机 TDMA 场景时明示组合方法。 | 真实轨迹驱动、无线链路由模型生成的半合成净吞吐与稳定性。 |

备选数据各有用途。AU-AIR 可补多旋翼运动与交通巡检，须先核对定位频率和真实重复次数；多视角高精度轨迹适合估计插值对 3 dB 判据的影响；TrajAir 适合载人通航的重复进场和交互；OpenSky 适合长时域路线统计。预先筛出的重复任务只支持相应任务类型。要估计实际业务的路线复用占比，需要有代表性的任务样本及清楚的分母。

## E　验证几何收益能否转化为净吞吐

- [ ] **E1　开阔视距基准。** 固定同一批轨迹、站点、噪声与外部信道随机场。以实际飞行高度、基站高度、水平和斜距、频率及地貌选择一档适用的空地模型，记录参数来源与超出适用范围的部分。
- [ ] **E2　先固定动作重放，再运行闭环。** 先冻结每种方法原有的时刻、指向、束宽和 MCS，在同一外部信道下重算接收质量、误块率及成功比特。再让所有方法在一致的因果反馈和链路自适应规则下重选动作。沿“指向损失 → 接收质量 → MCS/误块率 → 有效发送时间 → 净吞吐”逐层报告。若只看到几何改善，论文结论停在几何层。
- [ ] **E3　遮挡压力测试。** 可独立改变衰减、驻留时间和占比，使用同一组遮挡事件比较各方法；分别报告无遮挡、遮挡及恢复期。只有标量附加衰减时，结论限于所设掉落条件。要讨论遮挡后的最优指向，还需要反射路径的角度与功率信息。
- [ ] **E4　扩展攻击最强的假设。** 可按研究重点选用与感知波形、接收 SNR 和孔径一致的量测噪声及漏检、有限精度的通信导频辅助跟踪、MCS 实现余量扫描、CQI 反馈或计入资源成本的 HARQ。感知用独立波形时按其实际孔径建模。优先检验哪种假设会改变方案排序。

## F　实时性、复现与结论边界

- [ ] 测裸 IMM、RC 和各先进模型实际执行路径的 p50/p95/p99 延迟，包括特征、预测、误差头、控制与排队；记录硬件和批量。将测得延迟回灌到仿真，用新预测实际到达时的剩余期限做决策。
- [ ] 仿真开发、校准和确认性测试分开；同航线和同源滑窗按组管理，按世界或独立架次估计区间。随机训练模型建议 3 个种子复核，保存配置、数据划分、随机场和时间账本。
- [ ] 主工况建议 16 机、3.1 ms/1.667%，另以 3.1 ms/5% 作宽松参照，可加 9.3 ms/5% 判断单次感知成本影响。先做 1–2 个开发世界查账，再做两工况各 10 个验证世界、6–8 个方法（约 120–160 场）。锁定配置后，主工况用 30 个新世界（每套训练权重约 180–240 场）。网格搜索和重复训练另计。若验证方差表明 30 个世界难以分辨预定等效差，应在开启测试前调整样本量或预期结论。

## G　可放到扩展实验的选项

| 选项 | 在什么条件下值得做 |
| --- | --- |
| DLinear、iTransformer、PatchTST、TimesFM 等 | 分别需要轻量下限、多变量监督模型或另一个基础模型家族时。第一轮优先 Chronos-2、VECTOR、Moirai-2。 |
| TrajAirNet、Trajectron++、FlightBERT++ 等 | 有真实交互、明确邻机输入，或要专门研究航空预训练迁移时。 |
| 扩机数、改变路线复用比例、混入改道与冷启动 | 要给出方法适用的负载区间、复用条件和失效边界时。第七章提出的具体门槛先在独立工况验证。 |
| 信道感知数据调度、邻区干扰、非理想阵列、姿态误差 | 要拓展单站轮询的系统结论时。现有 value、EDF、uniform 分配感知与波束刷新，数据由 TDMA 轮询；修改数据调度后各方法须共用新规则。 |
| MPC、TabPFN 等 | 能明确回答现有对照尚未回答的问题，而且训练和在线计算成本可控时。 |

## 建议排期

1. **先做 A1–A3，同时做 B1–B2 和 D 的数据抽查。** 尽早发现 F 与 RC 是否有共同风险区、原生误差能否读出、真实航迹是否够长且可重复。
2. **打通 B3–B5，用少量验证世界跑 A4 的选点。** 完成 Chronos 的 CR-G 对照，再接 VECTOR、Moirai-2；此时记录实际运行成本。
3. **冻结配置并做 A4 的独立测试。** 交付 F 与 RC 同稳定性主图和先进模型完整闭环表。
4. **完成 D 的双类真实航迹主表。** 重复路线交付历史积累结果，多样路线交付自然抽样下的收益与回退代价。强调实际吞吐时加 L2 和适配信道，强调可实时部署时加延迟回灌。G 逐项取舍。
